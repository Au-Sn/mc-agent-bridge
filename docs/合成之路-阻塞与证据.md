## 因此：整条链只需要**一个外部输入**

只要下面任意一样进到世界 ✓，后面全部可以自动完成 ✓：

1. **一个工作台**（放在地上、或直接放进海龟背包 ✓）—— 海龟 `equip` 它之后就能合成一切 ✓
2. 或者 **一个原版容器**（箱子/漏斗/熔炉 ✓）里放一个工作台 ✓ —— 海龟 `suck` 就能取 ✓
3. 或者 **给那台 Inventory Manager 一张玩家绑定的记忆卡** ✓ —— 之后它就能读/搬所有容器 ✓（长期价值最大 ✓）

> 这与 `docs/自给清单.md` 第五节早就写下的结论一致 ✓：
> **"第一个工作台"是整条自给链上唯一不可约的外部输入** ✓ —— 今天用三条实测把这句话钉死了 ✓。

## 2026-09-18 追加：**大范围扫描**把这条路彻底判死了 ✗✓（证据强 4 倍）
