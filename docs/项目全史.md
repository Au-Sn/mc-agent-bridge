## 一、一句话与真正的目标

**交付物不是"假人会通关"**，而是**一个能换脑的「在场层」**：

> 任何 agent / 任何模型接上来，它都像一个玩家一样在场 ——
> 能看、能走、能动世界、能听会说、有自己的性格与记忆、出事不死、离开不散。
> 脑可插拔：换脑只改配置，不改游戏侧代码。

砍树、筛矿、产线那一类东西是**能力验收件**，用来证明"这个身体真能从零获取游戏内容"，不是终点。
"做完没有"要用 **D1~D7** 量（见 `docs/接口契约-伙伴v1.0.md §9`），不许用"它会做什么"量。

## 二、七个阶段：这个项目是怎么一步步来的

### 阶段 0 · 探索与选型（09-13 ～ 09-22）

**当时的问题**：怎么把一个"外部大脑"接进 Minecraft。

**做过的事**（留下 5 份专题文档）：
- 方案 C：CC:Tweaked + Advanced Peripherals（`plan-c-1.20.1.md`）
- **GPS 网络建设**：4 台计算机 ＋ 无线调制解调器，几何必须满足 CC ROM 的硬要求
  （4 台、3 台共面不共线、第 4 台离开该平面），最终 **4/4 主机应答**，海龟 `gps.locate` 精确返回
- **准星感知（Jade 效果）**：假人"正对着什么" —— 读出 `oak_planks @ (4128,70,12) 距离 3.07 面 west`
- **地图读取与寻路**：中间层思路成型
- **免界面合成**：KubeJS 服务端通路（后来被 `/dshcraft` 取代，成为兜底）

**这一阶段的收获**：把"游戏侧能提供什么"摸清了 —— 碰撞箱、方块 NBT、GPS、外设。
**教训**：GPS 那一族 bug 花了很久，四条真根因（调制解调器只连朝向那一侧、`/computercraft` 用实例号不用 ComputerId、新放的计算机开机前没有 ComputerId、`computer/<id>/` 目录可能不存在）全部写进 `GPS-建设记录.md`。

### 阶段 1 · 路线切换：从 CC 海龟到 Carpet 假人（09-23 ～ 09-30）

**决策**：身体不做成海龟，改成 **Carpet 假人**（服务端权威、能走能挖能放、能挂背包）。
留下 `plan-carpet-fakeplayer.md`、`carpet-route-progress.md`。

**同期启程的另一个主角**：自研模组 `dshbridge` 从 **2.13.3** 开始（09-23）。
它的定位是项目的 **L1 层**：约 25 条 `/dsh*` 指令 ＋ 按碰撞箱读世界 ＋ 驱动假人。

**这一阶段最痛的事**：**走路 8 红**（09-30）——
根因是"规划允许降 2~3 格，执行闸只认降 1 格"，两条判据口径不一致，
诊断文档 `诊断-走路8红-2026-09-30.md` 记下了根因与能走通的对照。

**沉淀下来的东西**：错题本（到 09-30 已积累 181 条编号里的绝大部分），
以及"**判据口径必须统一**"这条铁律。

### 阶段 2 · 能力面成型与验收契约（10-01 ～ 10-05）

这是项目第一次形成"**可交付的形状**"。

### 阶段 4 · 深度加固：身体与行为（10-25 ～ 10-31）

模组从 **2.24 一路到 2.45**，10-27 一天出了 **10 个版本**（2.27 ~ 2.36）。

重点是把"像玩家"落实到**动作层**：

- **皮肤系统**（`模组-皮肤系统.md`）

### 阶段 5 · 拟人化：规格先行（11-01）

用户给了一条硬要求：**"要做拟人化的部分时先停下制定模块"**。

于是先出规格（`方案-拟人化模块.md`，v1→v6，约 50 KB）：
- **N1~N10 反例**：不可能瞬移、不可能不知疲倦、不可能抽搐、不可能一次到位……
- **12 个模块**：A 任务、B 感知、C 动作原语、D 行为库、E 待机、F 自述、G 判据、H 记忆、I 施工许可、J 发言、K 蓝图、L 多智能体
- **里程碑 M1~M6**、延迟预算表、伤害策略表、保留策略

规格定完才动代码，当天实现的是 B / G / I / C / F / J 六个模块与它们的判据。

### 阶段 6 · 直连改造 ＋ 三条产线（11-01 ～ 11-02）

**事故**：我用一次 `fill` 把 y=71 那层 12×12 填成石头，其中正好包含 CC 桥接计算机
→ 整套系统断线（磁盘上 `computer/0/startup` 写着 "bridge / command computer"，
它的 `bridge_local` 修改时间正是我执行 fill 的那一分钟，因果闭合）。

**由此引出三条改造**：
1. **CC 计算机禁令**：5 个计算位置登记进 `no_dig` 禁区；新增 `bulk_guard`（没扫过 / 命中禁区 / 有方块实体，三条都拒绝），并把那次事故做成**回归测试**
2. **直连**：模组自己开 `127.0.0.1:8766` 的 HTTP 口（`/cmd`、`/raw`、`/health`）
   → 往返延迟从 **约 600 ms 降到 2~4 ms**
3. **`/raw` 服务器身份**：解开"拉假人要先有假人"的死结，重启后能全自动恢复

**产线**（用户："搭一个能用的产线，不一定要机械动力模组的"）：
- 虚空平台：x4145..4160 / z2..17 / y=70，256 格 stone，逐格验过
- 原版自动熔炼线：**端到端可用**，16 粗铁 → 16 铁锭
- Create 样机：`ploughing.nbt` 34/34 搭好（但是 gametest 样机，不产出）
- Mekanism 线：加工可用（电  料  出锭 ），差"抽出成品"要在界面配输出面

同期模组到 **2.56.0 → 2.57.0 → 2.58.0**（手部动画补齐：`digBlock` 和 `place` 原来都没挥手；这一段做 HTTP 加固/事件 trace/yaw 探针，以及构建去镜像/环境配置化）。

## 三、架构的演化

### 曾经的六层（09 月版）

| 层 | 是什么 | 位置 |
|---|---|---|
| L6 大脑 | 常驻会话 ＋ 耳＋嘴 | `tools/acp_serve.py`、`acp_talk.py` |
| L5 中间层 | 55 件 MCP 工具 ＋ 地图/规划/账本 | `tools/mc_mcp.py`、`mapread.py`、`pathplan.py` |
| L4 通道 | 网关（队列＋状态＋日志），单车道 | `gateway/agent_gateway.py` :8765 |
| L3 世界内 | CC 电脑取指令、以服务器权限执行、回执送回 | 世界里的 `cmd0`、`cc-tweaked/agent_bridge.lua` |
| L2 脚本 | KubeJS 补模组没做的 | `kubejs/dsh_*.js` |
| L1 模组 | `dshbridge`：`/dsh*` 指令 ＋ 按碰撞箱读世界 ＋ 驱动假人 | `mod/` |
| L0 世界 | ATM9 空岛 ＋ Carpet 假人 | `D:\pcl2\...` |

方向：指令往下走，数据往上走，**共用同一条通道** → 单车道 → 一次往返约 0.6 秒
→ **"调用次数"是这套系统最稀缺的资源**。

### 现在的两层半（11 月版）

```
Python  ── POST 127.0.0.1:8766 (2~4 ms) ──►  模组  ──►  假人
        └─ 后备：网关 8765 → CC 计算机 → 模组（只作保险）
```

**为什么改**：CC 计算机是又一个会坏的中间件（事实证明确实坏了）。
少一个中间件就少一个故障点，而且延迟降了两个数量级。

## 五、方法论：这个项目真正值钱的部分

1. **能力只能由它所在的那一层证明** —— 上层只是假设，必须回头验。
2. **判据先自检能红** —— 证明不了会失败的判据等于没有。
3. **没数据就说没数据** —— 宁可输出 `reason=xxx_unavailable`，也不瞎判。
4. **台账 ↔ 索引对账** —— 提交信息里提到的节号必须在正文存在，否则判据报悬空。
5. **判据必须进闸门** —— "写好了没进闸门就等于它不存在"（覆盖门守着）。
6. **世界真值优先** —— 校验只看方块/背包 NBT，不信执行者自述。
7. **把事故做成回归测试** —— fill 掉 CC 计算机那次，现在是 `bulk_guard_test` 的 G1。
8. **参数化而不是写死名字表** —— 工具选择用 `getDestroySpeed`、方块识别用方块实体、分类用标签。
