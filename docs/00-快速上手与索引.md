## 3. 十条命令，立刻能干活

```powershell
cd "<你的仓库路径>"

# ① 起全套（幂等；网关/皮肤/镜像/常驻会话/中继 —— 直连主路不需要网关，但耳+嘴要）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\start_all.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools\start_all.ps1 -ReloadMcp   # 改过 mc_mcp.py 之后

# ② 通道体检（直连优先）
py tools\direct.py --health          # 期望 ok dshbridge-http
py tools\world_alive.py              # 世界在跑吗（直连读两次 dshdigest 比 time=；后备才走旧 CC）

# ③ 离线闸门（**136** 项）+ 契约守恒 + D7 文档闸门
py tools\check_all.py --offline
py tools\contract_test.py
py tools\doc_consistency_test.py

# ④ 假人不在就拉回来（世界重启必然掉；自动核对生存模式）
py tools\respawn_bot.py

# ⑤ 一条指令一份态势 / 真正加载的模组版本 / 增量事件流
py tools\act.py cmd text="execute as Bot at Bot run dshdigest"
py tools\direct.py dshver
py tools\act.py cmd text="execute as Bot at Bot run dshevents"

# ⑥ 读方块的权威状态（含方块实体 NBT，诊断神器）
py tools\block_at.py --nbt 4122 71 3

# ⑦ 背包空位 ＋ 容器里有啥（只读）；满了先自动塞箱子（绝不丢地上）
py tools\inv_guard.py
py tools\inv_guard.py --auto

# ⑧ 台账索引（悬空必须 0）＋ 生成物重建
py tools\ledger_index.py
py tools\divergence.py --by-namespace

# ⑨ 全量电池（要游戏；离线闸门只是发货前那一关）
py tools\check_all.py

# ⑩ 改完模组：构建 ⇒ 验"新东西真在 jar 里" ⇒ **关进程重启游戏**（这一条省不得）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build_jar.ps1
py tools\install_mod.py
```

★模组指令要套 `execute as Bot at Bot run …`✗★（模组里用 `getPlayerOrException()`；命令源不是玩家会直接抛异常）。
