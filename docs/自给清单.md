# 自给清单（脚手架 vs 真本事）

> 立此文件的原因：用户明确要求 ——
> **"假人最后需要自己获取材料而不是从指令获取，也就是假人需要从零开始获取材料而不是直接拿。"**
>
> 所以 `/give` 只允许当作**脚手架**：它只能用来跳过"零起点"、把后面的环节先打通。
> 每给一样东西，都必须在这里写两件事：
> 1. 它换来了**什么验证**（不验证就不该给）；
> 2. 以后**怎么自己挣**（从零路径）。
>
> 最终验收标准：把本文件里所有"给定"的条目，一条条换成"自产"。
> 脚手架撤不掉的环节，就是真正的技术缺口。

## 一、已经证明"能自己获取"的能力（真本事，不是给的）

| 能力 | 证据 | 结论 |
|---|---|---|
| 砍整棵树 | `chop_tree` + `apotheosis:chainsaw`：一棵橡树整体掉落，掉落物**自动拾取** | 采集闭环成立 |
| 筛矿 | `sift` 连续模式：44 个砂砾 → 14 秒内产出 10+ 种矿物碎块，碎块**自动进背包** | 加工闭环成立 |
| 走位/贴边放置 | `sneak_place`（带逐步地板校验）在平台边缘成功放置，未坠崖 | 建造闭环成立 |
| 用方块/拉杆等 | `use_once` → 服务端 `useItemOn` 生效（拉杆 `powered:true`） | 交互闭环成立 |

**结论：采集、加工、建造、交互四条腿都验证过了。缺的不是"能不能"，是"合成"那条腿。**

## 二、真正的技术缺口：合成

- Carpet `/player` **没有 `craft` 子命令**（已从 jar 常量池确认）。
- 客户端专属能力，假人没有：按键绑定（FTB Ultimine）、任何 GUI/容器窗口、**潜行防坠（MC-93117）**。
- 因此"把原木变成木板、把木板变成工作台"这一步，假人自己做不了。

**补法（按优先级）：**
1. **海龟合成**：`turtle.craft()` 是服务端方块实体逻辑，不需要 GUI，现在就能用。
   → 之后的合成任务统一"假人给料 + 海龟合成"。
2. 后期换成机器自动合成（ATM9 里的各类机器），彻底去掉海龟这个中间人。

### 顺带记录一个关键推论：熔炼可以全自动、且不需要 GUI
假人点不开熔炉界面，但**漏斗可以**：
- 假人把燃料+矿石**丢在漏斗上** → 漏斗自动塞进熔炉；
- 熔炉下方接漏斗 → 产物被抽出后**从漏斗口掉出来** → 假人自动拾取。
- 全程不需要任何界面点击 ⇒ **"熔炼"不是缺口**，只要有漏斗（5 铁锭 + 1 箱子）就能自动化。

## 四、从零起步的完整闭环（目标剧本）

一夜之内能跑通的顺序（每步都用世界状态验收，不看自述）：

1. **徒手/木器阶段**：砍树 → 掉落自动拾取 → 假人把原木丢给海龟 → 海龟合成木板/木棍/工作台/木镐木斧
2. **石器阶段**：挖石头得圆石 → 海龟合成石镐石斧 + 锤子
3. **筛矿阶段**：海龟合成筛子（木板+木棍）→ 假人装网 → 连续 `sift` 出矿物碎块
4. **熔炼阶段**：挖沙做漏斗？——漏斗需铁；所以先：
   碎块 → 海龟合成矿物 → 需熔炼 → 用**第 2 个假人挖的煤炭**做燃料。
   早期可用：把矿石碎块合成为"生矿"后，投入**漏斗-熔炉-漏斗**流水线（见上面推论）。
5. **铁器阶段**：铁锭 → 铁网、漏斗、铁工具 → 真正进入自动化
6. **撤脚手架**：本文件第三节全表替换为"自产"，且全程不再出现 `/give`

### 已知需要"外部帮助"的两处（诚实记录）
- **熔炉/工作台本身**：来源是圆石+木板，可自产 ✓
- **初始那一个工作台**：木板就能做，海龟可代工 ✓
- （无真正必须外部干预的环节；唯一例外是"仪表"。）

## 五、**不可约的外部输入：第一个工作台**（2026-09-13 实测结论）

这是目前唯一一个**理论上无法由假人自己获得**的东西，必须诚实记录：

- 假人**没有 2×2 背包合成格**（那是客户端 GUI 的能力 ✗），也没有合成指令 ✗。
- 而"原木 → 木板"这一步**就发生在 2×2 里** ✗ → 没有工作台就做不出木板 ✗，
  没有木板就做不出工作台 ✗ —— **纯死循环** ✓。
- 实测佐证：半径 24×24×13 内**没有任何工作台**（`find_block crafting_table radius=24` ✓
  8125 格全扫 ✓ `found: 0` ✓）；海龟虽有 `craft` 动作 ✓ 但也**必须装备工作台**才能用 ✗
  （CC 的 Crafty 升级就是工作台 ✓ 同样需要先有一个工作台 ✗）。

**结论**：整条"从零自给"链上，**只需要外部投入一个工作台** ✓ 之后就永久闭环 ✓：
工作台在手 → 海龟 `equip` 它 → 海龟能合成木板/木棍/工具/筛子/第二个工作台 ✓ → 全部自产 ✓。

**获取方式（按优劣排序）**：
1. ✅ **世界现成物**：如果哪里的箱子/建筑里有工作台 ✓ 假人挖走或让 cc0 看箱子取出 ✓（**首选** ✓ 完全自给 ✓）。
2. ✅ **玩家手工给一个**：一次性投入 ✓ 记入本表 ✓。
3. ⚠️ `/give` 脚手架：允许 ✓ 但必须记录 ✓ 且只在 1、2 都不可行时使用 ✓。

> 这一条不是"做不到" ✓ 而是**"第一推动力必须来自系统之外"** ✓ —— 就像编译器需要先用别的编译器构建自己 ✓。
> 记在这里是为了**避免以后反复怀疑"为什么合成一直不成功"** ✗。
