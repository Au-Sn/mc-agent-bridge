   spawn 出来是**创造模式** ⇒ 必须立刻切生存 ✗ 否则"自给"证据全部失真（新的 recover 会做并回读确认）。

   ★绝不"丢在地上"腾位置✗★（会被它自己捡回来／丢远了 5 分钟消失）。

5. **本机环境**：只有 `powershell.exe`（**没有 PowerShell 7**）；`py` = Python 3。
   写文件用 Python 或编辑器 ✗ **PowerShell 会加 BOM／写 UTF-16／按 GBK 毁中文**（仓库被毁过一次，P91）。
   带中文的 `.ps1` **必须 UTF-8 BOM**（`tools/deploy_kubejs.ps1` 就是带 BOM 的）。
6. **沙箱**：`danger-full-access` 下命令才正常；`workspace-write` 下 shell 会 `0xC0000142` 崩（与项目无关）。

8. **模组指令要套 `execute as Bot at Bot run …`**（模组用 `getPlayerOrException()`；命令源不是玩家会抛异常）。
9. **进程归谁要当场核**（残留进程＋`SO_REUSEADDR` ⇒ 两个进程同时 bind，你读的是新进程的空日志；见 P7）。
