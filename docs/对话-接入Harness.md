```

  tools/dshrun.py ──③ 用 **Python** 起一个 harness 会话（`dsh --profile mcbot`）

        ▼
  mcbot 剖面（dsh-base ＋ dsh-headless ＋ 我们自己的 MCP 工具）
```

## 2. 为什么是"接入 harness"而不是"再写个脚本调 API" ✗

| | 直连 API（`--brain api` ✓ 老的 ✓） | **接入 harness（`--brain harness` ✓ 默认 ✓）** |
|---|---|---|
| 会说话 | ✓ | ✓ |
| **会做事** | ✗（只能产出文字 ⇒ 做事要靠外面写死流程 ✗） | ✓ **它手上真的有工具** ✓ |
| 定制角色 | 只能改那段 persona 字符串 ✓ | ✓ 换 `personas/*.md` ✓（还能直接改剖面/工具面 ✓） |
| 能看见世界 | 靠我们塞给它的文本 ✓ | ✓ 它**自己会去查** ✓（`bot_state` / `scan` / `bot_inventory` ✓） |
| 记忆 | 我们维护 `hist` ✓ | 每条消息一个**全新会话** ✓ 上下文靠"实况＋最近聊天"接上 ✓ |

★关键差别★ ✗：**harness 会话带着一整套工具与纪律** ✓ ——
"做不到就说做不到"这类要求 ✓ 在它的系统提示里本来就有 ✓ 再加上我们的人格文件 ✓ 所以它**不编** ✓（已实测 ✓）。

## 7. 已知代价与注意（如实写 ✓）

- **每条消息一个全新会话** ✗ ⇒ 它**不记得**上一轮的工具细节 ✓
  上下文靠 `dshdigest` 实况 ＋ 最近 8 句聊天接上 ✓（所以它不会"失忆到不认识你" ✓ 但别指望它记住十分钟前的中间过程 ✓）
- **真干活会慢** ✗（走路 20~90 秒 ✓）⇒ 靠**垫话**撑住体验 ✓ 别把 `--filler-after` 调大 ✗
- **垫话是写死的几句** ✗ —— 这是**中继层**的兜底 ✓ 不是它的"词汇量" ✗（它的正式回答全是现想的 ✓）
- **`--hold-quiet` 默认开** ✓：模组那句 canned 快嘴会让位 ✓ 代价是**自行走动也停** ✓
  （聊天时它本来就该站住看着你 ✓ talk.py 一停走动立刻恢复 ✓ 不必改模组 ✓）
- **不要同时跑两个 talk.py** ✗：都抢 `cmd0` ✓（同一时刻只有一个"嘴" ✓）
- **密钥**：harness 用自己的凭据（`~/.dsh/.credentials.yaml` ✓）⇒ 这条路**不需要** `secrets/deepseek.key` ✓
  （`--brain api` 才需要 ✓）

## 12. ★"说了就得做"★（用户要求 ✓ 2026-09-20 已实测 ✓）

用户原话 ✓：「和 bot 说的话也得让 bot 去执行」

**为什么不能只写在提示词里** ✗（本项目 P46 纪律 ✓）：
> **提示词是请求 ✓ 不是保证** ✗ —— 凡是"必须发生"的事，写进**代码** ✓

⇒ 做法（全在 `talk.py` ✓ 四步）：

1. **判**：带动作动词（去/搞/挖/砍/来/筛/给/帮…✓）⇒ 判成**指令** ✓
   - 带 `帮我/给我` ⇒ **一律**算指令 ✓（哪怕句尾带"吗"✓）
   - 句尾疑问词 ＋ 问能力（`你会…吗`✓`你能…吗`✓）⇒ **不算**指令 ✓（那是闲聊 ✓）
   - 有问号 ⇒ 不算 ✓；`干嘛/去过/了吗` 这类 ⇒ 不算 ✓
   - `--force-exec` ⇒ **每一轮都当指令** ✓（"我说啥你都得去做"模式 ✓）
2. **写进任务书** ✓：指令 ⇒ 任务书里直接写「★这一句是**指令**★★ ⇒ **必须真的去执行** ✓
   ★只回话＝没完成★ ✗」
3. **数** ✓：跑完去 `logs/mc_mcp.jsonl` **按时间戳数这一轮的工具调用** ✓
   —— ★这是唯一客观证据★ ✗（不靠模型自述"我做过了"✓）
4. **打回** ✓：是**指令**却 **0 次调用** ⇒ **强制重做一次** ✓
   （把「刚才那一轮你一个工具都没调 ✗」直接怼回去 ✓）⇒ 还是 0 次 ⇒ **照实记账** ✗
   （日志 `force=true acted=false` ✓ **不谎报** ✓）

**实测（两条路都验过 ✓）**：

| 场景 | 结果 |
|---|---|
| 正常路径：`!do 走到 (4127,71,4)` | 3 次工具调用 ✓（`say`+`walk_to`+`bot_state` ✓）答案坐标 4126.9,71,4.2 ✓ 与目标相符 ✓ |
| **打回重做**：故意用 `--force-exec` 配一句闲聊「一加一等于几？」 | 第一次 **0 次** ✗ ⇒ `[!] 强制重做一次` ✓ ⇒ 重做后 **1 次** ✓ 答案仍正确 ✓ |

—— ★它当场抓到一个真瑕疵★ ✗：`你会筛矿吗` 曾被判成**指令** ✗（会白跑一次重做 ✗）

## 14. 补记（2026-09-20 23:55 ✓）：诚实兜底 ＋ 硬前缀 ＋ 回归测试

### 14.1 ★出口的诚实兜底★ ✗（自己发现的漏洞 ✓）

漏洞 ✗：是**指令**、两次跑完却 **0 次工具调用** ⇒ 世界**一点没变** ✗
