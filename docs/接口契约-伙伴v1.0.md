## 1. 传输（★接入者最容易在这里踩死✗★）



**stdio ＋ 一行一条 JSON** ✗ —— `\n` 分隔 ✓ 一条消息一行 ✓



★**不是** LSP 那种 `Content-Length` 分帧✗★ ——

照 LSP 的习惯写客户端 ⇒ **永远读不到回执** ✗（这一条专门写出来，因为它不报错、只是静默卡住 ✓）



```

→ {"jsonrpc":"2.0","id":1,"method":"initialize","params":{}}

← {"jsonrpc":"2.0","id":1,"result":{"protocolVersion":"2024-11-05",

                                    "capabilities":{"tools":{"listChanged":false}},

                                    "serverInfo":{"name":"mc-bridge","version":"1.0.0"}}}

→ {"jsonrpc":"2.0","method":"notifications/initialized"}

→ {"jsonrpc":"2.0","id":2,"method":"tools/list"}

→ {"jsonrpc":"2.0","id":3,"method":"tools/call",

   "params":{"name":"whereami","arguments":{}}}

← {"jsonrpc":"2.0","id":3,"result":{"content":[{"type":"text","text":"…"}],"isError":false}}

```



- **未知工具／未知方法** ⇒ `-32601` ✓

- **工具内部抛异常** ⇒ 被接住 ⇒ `isError=true` ＋ 正文写 `工具**抛异常** ✗：<类型>: <消息>` ✓

  （★并**不**把异常抛给接入者✗★ —— 接入者不必自己兜 `-32603` ✓，但仍可能收到它 ✓）

## 2. 失败语义（★一处定义✗★）



1. ★**唯一的机器可读失败信号是 `isError`**✗★

   —— 正文是**中文** ＋ `✓✗★` 记号，**是给人读的** ✗

   ⇒ ★不许拿正文当判据✗★（同族：**P13**「中文回执过 CC 通道会全变 `?` ⇒ 拿它当判据 = 静默假阳性」✓）

2. ★**失败必须带原因**✗★（本项目纪律「让失败大声」✓）——

   只有一句"失败了"、没有现场数据的回执，**本身就算缺陷** ✓（**P116** ✓）

3. ★**没有"部分成功"这种含糊状态**✗★：

   要么 `isError=false` ✓；要么**明确说清哪一部分没做到** ✓

   （例：`chest_put_many` 会**动手前后各读一次**、逐件对账 ⇒ "没到数"的那几件会被点名 ✓）

4. **可重试性** ✗：读类工具天然幂等 ✓；**改世界**的工具（`dig_block`/`place_block`/`chest_*`/`sift`）

   ★不是幂等的 ✗★ ⇒ 重试前先读一次真值确认上一次到底做成了没有 ✓

## 3. 三条硬边界（★这是设计，不是缺陷✗★）



1. ★**没有 shell ／ 没有文件系统 ／ 没有网络**✗★ ——

   剖面 `mcacp` 里 `tool-pwsh` / `tool-fs` / `tool-fs-search` / `tool-subagent*` /

   `tool-workflow` / `tool-web` / `tool-skill` / `tool-jobs` **按 id 全关** ✓

   ⇒ ★模型**在结构上**发不出游戏指令✗★ —— 一切动作只能经由下面这些工具 ✓

2. ★**"说话"只有一个口子**✗★：`say`（以及它最后那句自动播报 ✓）；

   ★出去的中文会被转义成 `U+XXXX` 再由模组解回来✗★（**P38/P136** ✓）

3. ★**单车道**✗★：一台 CC 电脑**一次只吃一条**指令 ⇒ 一次桥往返 ≈ **0.6 秒** ⇒

   ★**"调用次数"是本系统最稀缺的资源**✗★（**P97** ✓）

   ⇒ 所以工具里有 `whereami` / `survey` / `route_view` 这种"**一次调用说完一整件事**"的聚合件 ✓

## 5. 接入者必读的五条纪律（★每一条都是本项目用事故换来的✗★）



1. **动手前先看**：`whereami`（我在哪、周围有什么、离边几步）＋ `look`（准星够不够得着 ✓）

2. **远距离一律 `walk_route`** ✗ —— ★不要用 `walk_to` 硬走长腿✗★：

   空岛单发长走会贴边绕，**实测掉过两次虚空、丢过整包东西**（钻石／斧／漏斗／锤子／麦子 ✓）

   `walk_to` 自己也会 **>8 格拒发** ✓

3. **会改变世界的事先 `freeze`** ✓（搬东西／挖放／对账 ✓）—— 否则"我读两次"之间**世界在动** ✗

   ⇒ 会把"假人自己溜达"误判成"丢东西" ✗（**P94/P96/§40.7** ✓）

4. **不止一步的事 ⇒ 账本** ✓：`job_open` → `job_plan`（一行一步「做什么 ｜ 怎么算做成了」✓）→

   每步 `job_step` **带世界真值证据** ✗（没证据会被**拒绝** ✓ —— **P122** ✓）

5. **验收一律用世界真值** ✗：图 ≠ 世界 ✓ 自报 ≠ 事实 ✓

   （★"我查过了"和"我查对了"不是一回事✗★ —— **P149** ✓）
