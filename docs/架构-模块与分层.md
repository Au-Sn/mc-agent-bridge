## 4. ★★分层最要紧的一条纪律：**能力只能由它所在的那一层证明**★★ ✗

- 例 ✓（**第 34 轮的真实翻车** ✗）：我判断"**模组能不能跳**"✗ 用的却是
  **L5 的几何推断 + 只拿 1.5 格高的墙做样本** ✗ ⇒ 得出"**模组不会跳**"✗ —— **错了** ✗
  真值在 **L1**：源码 3687/3725 行写着 `wantJump` ＋ `setDeltaMovement(...,0.42,...)` ✓
  ⇒ 起跳 0.42 ⇒ **约 1.25 格** ✓ ⇒ **整方块能上** ✓ **1.5 的墙谁都不行** ✓（模组自己也注释了 ✓）
- ⇒ **纪律** ✗：
  ① 说"某层做不到某事"✗ ⇒ 必须**在该层的证据**上成立 ✓
     · 世界能不能站 ⇒ **L1（碰撞箱）** ✓
     · 模组能不能到 ⇒ **L1 的移动循环**（跳/绕/落差 ✓）✓
     · 我"以为"能不能 ⇒ **L5** ✓（★那只是假设 ✗ 必须回头验 ✓）
  ② **样本要盖住那一类** ✗：拿墙当样本 ⇒ 只能证明"**墙**跳不上去"✗ 不能证明"模组不会跳"✗
  ③ 结论写成**带条件**的 ✗：「**整方块能跳、1.5 的墙不能跳**」✓ 而不是「**它不会跳**」✗
