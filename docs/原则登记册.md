1. **记录**：每条原则 = `{原则, 出处, 作用域, 已知例外}`。★作用域必须写到"**哪些代码要遵守**"✗★，
   否则没人知道什么时候该回头看一眼 ✓
2. **出生门**：任何新模块除了"先写一句职责"，★还要再过一遍登记册里**作用域匹配**的条目✗★ ——
   在模块头注里写明"★本模块与第 N 条的关系✗★"（遵守 ／ 例外 ／ 不适用，三选一，必须显式）。
3. **TEMPORARY 强制标签**：任何"先这样跑"的方案进欠账表**必须**带
